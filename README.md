# Adobe Add-In: Lesezeichen-Sortierer

Sorts PDF pages by bookmarks and auto-generates a table of contents in Adobe Acrobat.

A JavaScript add-in for Adobe Acrobat that reorders PDF pages to match the bookmark tree
and optionally inserts a generated table of contents page.
